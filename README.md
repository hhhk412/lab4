## Описание проекта

Двумерная аркадная игра «Астероиды», реализованная на языке Python с использованием графической библиотеки `tkinter`. Игрок управляет космическим кораблём в пространстве с тороидальной геометрией, уклоняется от вращающихся астероидов и уничтожает их ракетами. Реализована покадровая анимация взрывов, динамический параллакс-фон и физика инерции с сопротивлением среды.

## Функциональные возможности

### Основной функционал
- Стартовый экран с интерактивной заставкой (запуск строго по клику на прямоугольник заставки)
- Неподвижный космический фон и динамический движущийся фон астероидов
- Управление кораблём с клавиатуры: вращение, ускорение с анимацией пламени двигателя, стрельба ракетами
- Физика движения с инерцией и постепенным замедлением (сопротивление среды)
- Тороидальная геометрия игрового поля (телепортация объектов при пересечении границ экрана)
- Генерация астероидов со случайными линейными и угловыми скоростями
- Расчёт столкновений ракет и корабля с астероидами, система жизней и подсчёт очков
- Покадровая (тайловая) анимация взрывов из 24 фаз при уничтожении объектов

### Дополнительный функционал
- Модульные тесты игровой физики, тороидальной геометрии и коллизий (`unittest`)

## Требования к системе

- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** стандартная библиотека Python (`tkinter`, `math`, `random`, `unittest`)

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd lab4
```

### 2. Создание и активация виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Проверка зависимостей
Сторонние пакеты не требуются (используется встроенный модуль `tkinter`):
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Запуск модульных тестов
```bash
python -m unittest discover -s tests
```

### 6. Управление в игре
- **ЛКМ по заставке** — старт / перезапуск игры
- **Стрелка влево / вправо (`←` / `→`)** — вращение корабля вокруг своей оси
- **Стрелка вверх (`↑`)** — включение двигателя (ускорение корабля)
- **Space (Пробел)** — выстрел ракетой

## Структура проекта

```text
lab4/
├── .gitignore               # Исключение временных файлов кэша Python
├── README.md                # Документация проекта
├── requirements.txt         # Описание требований к окружению
├── main.py                  # Точка входа в приложение
├── venv/                    # Виртуальное окружение проекта
├── src/
│   ├── __init__.py
│   ├── config.py            # Глобальные константы и настройки физики
│   ├── app.py               # Главный контроллер игры, окно и цикл обновления
│   ├── models/
│   │   ├── __init__.py
│   │   └── game_objects.py  # Игровые сущности: корабль, астероиды, ракеты, взрывы
│   └── renderers/
│       ├── __init__.py
│       └── renderer.py      # Отрисовка сцены, спрайтов и интерфейса на Canvas
└── tests/
    ├── __init__.py
    └── test_physics.py      # Модульные тесты математики и столкновений
```

**Назначение основных модулей:**
- `main.py` — инициализация и запуск приложения.
- `src/config.py` — централизованное хранение параметров экрана, скоростей и таймингов.
- `src/app.py` — управление состоянием игры, обработка событий клавиатуры и мыши, игровой таймер.
- `src/models/game_objects.py` — объектная модель сущностей, расчёт кинематики, тороидальных координат и коллизий.
- `src/renderers/renderer.py` — визуализация игрового поля, анимация двигателя и взрывов.
- `tests/test_physics.py` — проверка корректности расчёта расстояний, переноса границ и столкновений.
